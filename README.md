# Axon: adaptive brain training for Android

Axon is a brain-training app with **10 games built on classic cognitive-science tasks** (reaction time, symbol
coding, mental math, number series, Corsi blocks, n-back, Stroop, flanker, task switching, card sorting) and a
**Bayesian engine** that estimates your ability in every skill and picks the level where you succeed about 80% of
the time. That's the sweet spot for learning.

This repository hosts the **Android releases** (APK files).

## Install

1. On your phone, open **[Releases → Latest](../../releases/latest)** and download `axon-vX.Y.Z.apk`.
2. Open the file and allow installs from your browser when Android asks.
3. If Play Protect says the developer is unknown, choose **Install anyway**.

Requires Android 7.0 or newer.

## Updates

The app checks this repository for a new release every few hours (or right away via
*Settings → Updates → Check now*). When one is available, tap **Install**: the new version installs over the old
one and keeps all your progress.

## Privacy

No account, no ads, no analytics. Your training data stays on your phone. The only network request the app makes is
reading this repository's latest release to look for updates.
